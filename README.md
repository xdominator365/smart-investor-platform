# AI Investing Platform

A modular platform for building AI-driven investing and trading systems.

## Projects
- **ai-investor**: Paper trading platform with AI signals, charts, and portfolio tracking

## Tech Stack
- Backend: FastAPI, PostgreSQL, SQLAlchemy, Alembic
- Frontend: React, TypeScript, Tailwind, Recharts
- ML (planned): Feature stores, model registry, backtesting

## Roadmap
- ML-based strategies
- Backtesting engine
- Multi-user support
- Broker integrations (Zerodha)
